## Decisions Made

- **Loud-fail on unknown runtime.** gsd-build's upstream `default:` branch silently falls back to Claude paths for unknown runtime IDs. We throw `RangeError` instead — typos in caller code (e.g., `'claud'` vs `'claude'`) should surface at the resolver, not silently route to the wrong directory. The error message lists all 14 known IDs.
- **D-10 lock at the resolver layer.** The plan calls out that hermes/grok should not be in our switch. We enforce this twice: (a) no `case 'hermes'` or `case 'grok'` branches present; (b) a dedicated test asserts that calling `getGlobalConfigDir('hermes')` throws `RangeError`. Phase 24's 14-runtime invariant cannot be silently violated through this module.
- **Pure module, side-effect-free at module load.** Only `os` and `path` are `require()`'d at the top level. No `fs.*` calls anywhere. No `process.env` writes. This means downstream callers (`runtime-artifact-layout.cjs` per Plan 28.7-02, `installer.cjs` per Plan 28.7-08) can `require()` this at any point without triggering filesystem reads or env mutations.
