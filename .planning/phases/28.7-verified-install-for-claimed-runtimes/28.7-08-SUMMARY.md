# Phase 28.7 Plan 08: Wave C.1 — Installer Wiring (Multi-Artifact Dispatch) Summary

## TL;DR

Wave C.1 replaces the broken Phase 24 `agents-md` placeholder (single AGENTS.md/GEMINI.md drop per runtime — D-02 "broken placeholder") with the **multi-artifact dispatch pipeline** wired into the existing installer. `installer.cjs` now branches on `runtime.kind ∈ {claude-marketplace, multi-artifact}`, with the multi-artifact branch driving `runtime-artifact-layout.cjs` → per-runtime converters → per-file `writeFingerprinted`. **Cline is the only special case** (layout.specialCase === 'clinerules-embed' → `installCline` → `buildClinerulesFile` → single `.clinerules` file per D-09). **All 14 runtimes now produce real-shape output** (skills/<name>/SKILL.md or command/<name>.md or commands/gdd/<name>.md or .clinerules — per `runtime-artifact-layout.cjs`). **CLI surface unchanged** — backward-compat with every flag (`--<runtime>`, `--global`, `--local`, `--dry-run`, `--config-dir`, `--uninstall`, `--all`, `--help`, `--no-peer-prompt`, `--register-mcp`, `--no-register-mcp`) preserved; the only `scripts/install.cjs` change is a one-line scope passthrough required by D-07. **Phase 26 D-06 models.json side-effect preserved** for all 14 runtimes. **Foreign-file protection extended** to recognize all three fingerprint shapes (Phase 24 PLUGIN_FINGERPRINT + Phase 28.7 GDD_ADAPTER_FINGERPRINT + Phase 28.7 CLINERULES_HEADER_FINGERPRINT) — without this extension every re-install would skip-foreign 70 files instead of detecting idempotence. **`npm test`: 2472 pass / 0 fail / 20 skipped.**

### Task 2: Rewrite installer.cjs core flow for multi-artifact kind + extend isPluginOwned (commit 37b6c6b)

Replaced `installAgentsMd` / `uninstallAgentsMd` (the Phase 24 placeholder that dropped a single AGENTS.md/GEMINI.md per runtime) with:

- **`installMultiArtifact(runtime, configDir, dryRun, opts)`** — resolves scope → calls `resolveRuntimeArtifactLayout(runtime.id, configDir, scope)` → calls `findInstallSourceRoot(configDir)` → enumerates available skill names (`listSourceSkills`) → branches to `installCline` for `layout.specialCase === 'clinerules-embed'` → else iterates `for (kind of layout.kinds)` calling `kind.stage(ctx)` then `writeFingerprinted(computeDestPath(configDir, kind, item.name), item.content, dryRun)` per staged item.
- **`uninstallMultiArtifact(runtime, configDir, dryRun, opts)`** — symmetric to install. Walks the layout, for each expected destination checks `fs.existsSync` then `isPluginOwned(content)` then `fs.unlinkSync`. Empty per-skill subdirectories (`<configDir>/skills/<name>/`) are best-effort `fs.rmdirSync`'d after their SKILL.md is removed. Top-level `skills/` + `commands/` dirs are NOT removed (may host user-authored content).
- **`installCline` / `uninstallCline`** — D-09 special case. `installCline` reads each source SKILL.md, calls `cline.cjs#convert(content, name, { runtime: 'cline' })`, accumulates `{ name, block }` entries, then calls `cline.cjs#buildClinerulesFile(blocks)` for the final string. Single `.clinerules` write via `writeFingerprinted`.
- **`computeDestPath(configDir, kindDescriptor, itemName)`** — implements the kind-to-path table: `skills` → `<configDir>/<destSubpath>/<itemName>/SKILL.md`; `commands` → `<configDir>/<destSubpath>/<itemName>.md`; `agents` → `<configDir>/<destSubpath>/<itemName>.md`.
- **`writeFingerprinted(target, desired, dryRun)`** — atomic, fingerprint-aware single-file writer. Four-action result matrix: `created` / `updated` / `unchanged` / `skipped-foreign`. Recursively ensures parent dirs exist via `ensureDir(path.dirname(target), dryRun)`.
- **`aggregateAction(perFileResults)`** + **`aggregateUninstallAction(perFileResults)`** — collapse per-file results into a single top-level action with priority `skipped-foreign > created > updated > unchanged` (install) and `skipped-foreign > removed > unchanged` (uninstall).
- **`detectMultiArtifactInstalled(runtime, configDir, opts)`** — best-effort scan of the layout-resolved destination dirs for any plugin-owned file. Cline special case: single `.clinerules` content check. Never throws (peer-detection use-case).
- **Module exports** extended with `installMultiArtifact` + `uninstallMultiArtifact` for Plan 28.7-09's per-runtime simulation tests.

**Claude branch UNCHANGED:** `installClaudeMarketplace` / `uninstallClaudeMarketplace` preserved verbatim. Settings.json merge + `enabledPlugins[<name>@<marketplace>]` flip identical to Phase 24.

**Phase 26 D-06 preserved:** `installModelsJson` / `uninstallModelsJson` / `buildModelsJsonPayload` / all `MODELS_JSON_*` constants exported and unchanged. `result.modelsJson` side-effect attached to every install / uninstall result (independent of kind).
