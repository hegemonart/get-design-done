## Decisions Made

- **Two-runtime XDG `command/` family (opencode + kilo):** both runtimes use the same singular `command/<name>.md` layout — the converters are byte-identical except for runtime string + display label. Could have been a single parameterized converter, but the modular one-file-per-runtime pattern (D-08) keeps each converter independently navigable and matches the existing 11-converter precedent. Cost is ~60 LOC duplication; benefit is uniform mental model across all 13 runtimes.
- **GEMINI_TOOL_MAP locked at exactly the Phase 21 reference doc:** all 8 CC→Gemini pairs from `reference/gemini-tools.md` are encoded; Task is intentionally absent. The lock-test pattern from D-06 enforces this: if `reference/gemini-tools.md` changes, the dedicated structural test (`gemini GEMINI_TOOL_MAP matches Phase 21 reference`) must be updated alongside the converter — a deliberate paired-change requirement.
- **Adapter display labels honor official runtime branding:** OpenCode (not "Opencode" or "OPENCODE"), Kilo (not "KILO"), Gemini (not "GEMINI CLI"). Verified by 3 dedicated `<runtime> adapter` header tests.
- **GEMINI_TOOL_MAP exported alongside convert:** unlike codex (whose CODEX_TOOL_MAP lives in shared.cjs), Gemini's map is converter-local and exported. This matches augment.cjs (AUGMENT_TOOL_MAP) — both are runtime-specific maps that don't make sense outside their converter. Tests can `require('...gemini.cjs').GEMINI_TOOL_MAP` and introspect without re-defining the 8 pairs.
- **Wave B closure encoded as a test, not a comment:** the test `'Wave B complete — 13 runtime converter files exist'` enumerates all 13 expected runtimes, asserts each `.cjs` is present, asserts hermes/claude are absent, and asserts the total file count is 14. If Plan 28.7-08 (installer) accidentally adds another converter file, or if a future refactor removes one, this test fails loudly. Same enforcement style as the D-10 hermes-absent guard from Plan 28.7-06.
- **Defensive prose-passthrough on Gemini:** the converter does NOT rewrite tool-name mentions in prose (only the parenthesized in-fence invocation form). Test `gemini preserves prose mentions of Claude tool names` asserts "The Bash tool" and "Bash tool and Read tool are mentioned" survive verbatim. This matches codex.cjs and augment.cjs policy (D-06 invocation-only rewrite).
