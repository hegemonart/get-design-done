# Phase 28.7 Plan 03: Runtime Slash-Command Surface Summary

**Per-runtime slash-command emitter mapping a bare command name (e.g. `explore`) to the runtime's expected shape: codex `$gdd-explore` (shell-var), all 13 others `/gdd-explore`. Idempotent across six prior input shapes; argument tails round-trip verbatim for Windows-path safety.**

## What shipped

### `scripts/lib/install/runtime-slash.cjs` (172 LOC)

Module exports (exactly three):

- **`formatGddSlash(commandName, runtime)`** — pure rewrite of a single command token.
  - Type-guard: non-string input passes through unchanged.
  - Empty string → `''`.
  - Strips any of `/gdd-`, `/gdd:`, `gdd-`, `gdd:`, `$gdd-`, `$gdd:` (case-insensitive) via regex `^[/$]?gdd[-:]/i`.
  - Empty / whitespace-only after stripping → `''` (defensive: never emit `/gdd-` or `$gdd-` with no token).
  - Splits on first whitespace; only the leading token is rewritten, the tail round-trips untouched.
  - codex → `$gdd-<token-lowercased><tail>`.
  - all others → `/gdd-<token><tail>` (token case preserved).
  - Unknown / falsy runtime defaults to claude shape.

- **`resolveRuntime(projectDir)`** — read-only runtime ID resolver.
  - Precedence: `process.env.GDD_RUNTIME` > `<projectDir>/.planning/config.json#runtime` > `'claude'`.
  - Result is always lowercased.
  - Malformed JSON, missing file, or missing `runtime` key all silently fall through — NEVER throws.

- **`formatGddSlashFor(projectDir, commandName)`** — convenience wrapper: `formatGddSlash(commandName, resolveRuntime(projectDir))`.

Private helper:

- **`stripGddPrefix(s)`** — single-pass regex strip of any of the six prior shapes. Used by `formatGddSlash` only.

Per-file header cites gsd-build/get-shit-done (MIT) origin (D-02). Notes the gsd- → gdd- brand swap and Phase 28.7 D-11 v1 scope.

Coverage (grouped):

**Emission (4 tests):**

3. 5-runtime sample (cursor, windsurf, kilo, opencode, antigravity) all emit `/gdd-debug`.

**Idempotency (4 tests):**
5. `/gdd-debug` under claude stays `/gdd-debug`.
6. `$gdd-debug` under claude normalizes to `/gdd-debug`.
7. `$gdd-debug` under codex stays `$gdd-debug`.
8. Legacy `/gdd:foo` and `gdd:foo` under claude normalize to `/gdd-foo`.

**Argument tail (3 tests):**
9. `do --phase 1` under claude → `/gdd-do --phase 1`.
10. Windows path in tail under codex (`open C:\Users\Me\file.txt`) preserved verbatim → `$gdd-open C:\Users\Me\file.txt`. Token lowercased, tail case preserved.
11. Tab-separated tail preserved.

**Degenerate inputs (3 tests):**
12. Empty string → `''` for both claude and codex.
13. Whitespace-only (`   `, `\t\t`) → `''`.
14. Bare prefix `gdd-` / `/gdd-` / `$gdd-` with no token → `''` (defensive against re-emission with empty tail).

**Type-guard (1 test):**
15. Non-string input (null, undefined, 42) passes through unchanged.

**resolveRuntime (6 tests):**
16. `GDD_RUNTIME` env wins even when `.planning/config.json` says otherwise.
17. `.planning/config.json#runtime` honored when env unset.
18. Defaults to `'claude'` when env unset + no `projectDir`.
19. Malformed JSON (`not valid json {[}`) does NOT throw; defaults to `'claude'`.
20. Missing `runtime` key in valid JSON defaults to `'claude'`.

**formatGddSlashFor delegation (2 tests):**
22. Project with `runtime='codex'` in config.json → `formatGddSlashFor(dir, 'explore')` returns `$gdd-explore`. Tested with two different commands to verify it's not first-arg cached.
