## What shipped

### `scripts/lib/install/runtime-artifact-layout.cjs` (431 LOC)

Exports:

- **`ALLOWED_RUNTIMES`** — `Set` of 14 GDD runtimes (D-03 lock). Explicit comment noting hermes + grok are intentionally absent.
- **`findInstallSourceRoot(runtimeConfigDir?)`** — walks up from `__dirname` looking for `skills/`. Optional `.gdd-source` marker override under `<configDir>` for test fixtures.
- **`resolveRuntimeArtifactLayout(runtime, configDir, scope='global')`** — main public API. Validates inputs (TypeError on empty configDir / invalid scope / unknown runtime). Switches over 14 runtimes returning `{runtime, configDir, kinds[]}`.

Layout table (locked by D-03 + D-09 + D-10):

| Runtime     | global kinds[]                                          | local kinds[]                                                  |
|-------------|---------------------------------------------------------|----------------------------------------------------------------|
| claude      | `[skills@'skills', passthrough]`                        | `[commands@'commands/gdd', passthrough; agents@'agents', passthrough]` |
| cursor      | `[skills@'skills', ./converters/cursor.cjs]`            | (same)                                                         |
| gemini      | `[commands@'commands/gdd', ./converters/gemini.cjs]`    | (same)                                                         |
| codex       | `[skills@'skills', ./converters/codex.cjs]`             | (same)                                                         |
| copilot     | `[skills@'skills', ./converters/copilot.cjs]`           | (same)                                                         |
| antigravity | `[skills@'skills', ./converters/antigravity.cjs]`       | (same)                                                         |
| windsurf    | `[skills@'skills', ./converters/windsurf.cjs]`          | (same)                                                         |
| augment     | `[skills@'skills', ./converters/augment.cjs]`           | (same)                                                         |
| trae        | `[skills@'skills', ./converters/trae.cjs]`              | (same)                                                         |
| qwen        | `[skills@'skills', ./converters/qwen.cjs]`              | (same)                                                         |
| codebuddy   | `[skills@'skills', ./converters/codebuddy.cjs]`         | (same)                                                         |
| cline       | `[]` + specialCase='clinerules-embed' (D-09)            | (same)                                                         |
| opencode    | `[commands@'command', ./converters/opencode.cjs]`       | (same)                                                         |
| kilo        | `[commands@'command', ./converters/kilo.cjs]`           | (same)                                                         |

Every `kinds[].prefix === 'gdd-'`. Every non-cline `kinds[].stage` is a function (lazy require).

Factory helpers (private):

- `skillsKind(destSubpath, prefix, converterPath, runtime)` — wraps stage callback that reads `<skillsRoot>/<name>/SKILL.md` and optionally converts.
- `commandsKind(destSubpath, prefix, converterPath, runtime)` — same shape, `kind:'commands'`.
- `agentsKind(destSubpath, prefix)` — claude-local only, passthrough copy from `<repo>/agents/<name>.md`.

## Deviations from Plan

None — plan executed exactly as written.

Notable design choices made within the plan's degrees of freedom:

- **D-09 routing hint surface area.** Plan said "cline: kinds = []". Plan also said "cline returns `kinds: []` + special-case marker `{ specialCase: 'clinerules-embed', converterName: 'cline' }`". I implemented both: the empty kinds[] AND a `specialCase` + `converterName` attached to the layout object so Plan 28.7-08's installer can detect cline without scanning for empty arrays. Test #9 asserts both.
- **`commandsKind` accepts a converter path.** Plan's layout table column shows gemini/opencode/kilo with converter references; claude local commands has none (passthrough). I made `converterPath=null` the passthrough signal across both factories — consistent with `skillsKind` for claude global.
- **`agentsKind` reads from `<repo>/agents/<name>.md`.** Plan didn't spell out the source path for claude-local agents. I used `<skillsRoot>/../agents/<name>.md` based on the GDD repo layout (skills/ and agents/ are siblings). If a Plan 28.7-08 reviewer wants this routed differently, the change is local to one factory function.
