### Task 2: Golden-fixture tests for Wave 2 converters

Created `tests/converters-wave2.test.cjs` (297 LOC, **55 test cases**) modeled on `tests/converters-wave1.test.cjs`. Test groupings:

1. **Loop-based shared invariants (10 tests × 4 converters = 40):** export shape, frontmatter, description round-trip, name-prefix normalization, single adapter header, idempotency, non-empty string output, minimal-input handling, no-frontmatter-input handling, `/gdd-*` slash form preservation.
2. **Claude-compat tool passthrough (1 test × 3 converters = 3):** windsurf/trae/qwen preserve `Bash(`, `Read(`, `Edit(` verbatim and do NOT emit `launch-process(` or `shell(command=`.

4. **Per-converter adapter sanity (3 tests):** windsurf/trae/qwen each have a dedicated "injects <Display> adapter header" test (augment's is covered in the augment-specific block above).
5. **D-02 attribution lint (1 test):** reads windsurf/augment/trae/qwen and asserts each file contains the string `gsd-build` + starts with `'use strict';`.

## Decisions Made

- **AUGMENT_TOOL_MAP placement:** per-runtime file (augment.cjs), not shared.cjs. Rationale: cross-cutting maps (codex was a Phase 21 reference) belong in shared; runtime-specific maps stay with their consumer.
- **Augment scope:** only Bash + Edit mapped. Read/Write/Grep/Glob/WebSearch/WebFetch pass through. `Write` deliberately left unmapped — Augment's documented surface uses str-replace-editor for edits but the dedicated "write a new file" form is less well-documented; conservative passthrough preferred over speculative mapping.
- **Qwen Claude-compat:** confirmed by gsd-build precedent (runtime-artifact-layout.cjs#case 'qwen' explicitly delegates to Claude-shape conversion). qwen.cjs uses the same shape as cursor/copilot/antigravity/windsurf/trae — no tool map.
- **Length-stability invariant (claude-compat <5% spread):** at-minimum form of the plan's "byte-identical golden fixture" deliverable. Cheaper to maintain than byte goldens; still catches structural regressions.
