## The conversion algorithm

```
Claude SKILL.md (source)
    │
    ├─→ extractFrontmatterAndBody  → { frontmatter, body }
    │
    ├─→ buildFrontmatter(fm, name, 'gdd-')  → "---\nname: gdd-<n>\n...---\n"
    │
    └─→ body
            │
            ├─→ rewriteSlashRefs(body, runtime)        [prose only]
            │       • cursor/copilot/antigravity → /gdd-<n>
            │       • codex                       → $gdd-<n>
            │
            ├─→ rewriteCodeFenceTools(out, toolMap)    [fenced only]
            │       • cursor/copilot/antigravity → no-op
            │       • codex → CODEX_TOOL_MAP: Bash(→shell(, Read(→read_file(, …
            │
            └─→ ensureAdapterHeader(out, 'Cursor'|'Codex'|...)
                    • prepends `<!-- gdd: auto-generated ... <X> adapter -->`
                    • idempotent: first-500-char marker scan, single injection

→ frontmatter + body  ⇒  destination SKILL.md
```

The prose-vs-fence split is the core invariant: the two rewriters use the same coarse code-fence splitter (`splitByCodeFence`) but operate on opposite-parity segments. Prose stays prose; code stays code.
