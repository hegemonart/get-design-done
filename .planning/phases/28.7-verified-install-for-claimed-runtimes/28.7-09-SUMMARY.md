## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] installer.cjs ignored scope for claude → claude --local silently wrote settings.json**

- **Found during:** Task 2 (per-runtime simulation suite) — the dedicated `install-per-runtime: claude local writes commands/gdd + agents` test failed with `ENOENT: commands/gdd/gdd-sample.md`.
- **Issue:** `installRuntime` short-circuited on `runtime.kind === 'claude-marketplace'` regardless of scope. The `runtime-artifact-layout.cjs#claude` switch case has had a proper `scope === 'local'` branch since Plan 28.7-02 (`commandsKind('commands/gdd', 'gdd-', null, 'claude') + agentsKind('agents', 'gdd-')`), but the installer never dispatched to it. Plan 28.7-08's installer refactor preserved the original kind-only dispatch under the "carry-forward invariant — claude branch untouched" guard.
- **Fix:** In both `installRuntime` and `uninstallRuntime`, when `runtime.kind === 'claude-marketplace'` AND `scope === 'local'`, dispatch through `installMultiArtifact` / `uninstallMultiArtifact` instead of the marketplace path. `claude --global` still routes through `installClaudeMarketplace` (unchanged). The fix is 6 lines per function (12 lines + comment block).
- **Files modified:** `scripts/lib/install/installer.cjs` (installRuntime + uninstallRuntime dispatch branches)
- **Verification:** `node --test tests/install-per-runtime.test.cjs` — 26/26 pass including the claude-local test. Full repo sweep stays at 2498/2498 pass (no regressions in install-merge / install-runtimes / install-models-json / install-script test suites).
- **Committed in:** `3a7ffb5` (separate `fix(28.7-09)` commit, surfaced before the test suite commit).
